## Layout agreed
```
core/
  mds.py              MDS-MAP steps: shortest_path_distances, classical_mds, align_to_anchors, mds_map
  derivatives.py      class Model: residuals, loss slope, gradient, Jacobian, Huber weights
  initialization/     one file per family of starting points, same signature f(param) -> x
    baseline_initialization.py   from_x0, random_start, mds_start (calls core/mds.py)
baseline_solvers/
  pgd.py, lm.py       each file: the method + solver() = its baseline composition
solver.py             final solver, imports core/
```
- Initialization has its own package because it will be explored heavily; new strategies go in new files.
- `math.py` avoided (shadows the standard library `math`).
- Baseline methods stay frozen in `baseline_solvers/`; improved copies go in `core/` when the final solver needs them.
- Files under `baseline_solvers/` need the repo root on `sys.path` (the runner only adds the solver file's own folder).

## MDS choices (see `papers/`)
| Choice | Source |
|---|---|
| Shortest paths fill missing distances | Shang et al. 2003, §2.2 step 1 |
| Classical MDS, top-q eigenpairs | Shang et al. 2003, Eq. 1 / step 2 |
| Scale + rotation/reflection + shift fit to anchors (least squares) | Shang et al. 2003, §2.2 step 3 |
| No local minima, sensitive to range errors, O(n³) | Patwari et al. 2005, p. 65 |
| Error ≈ half radio range at ~12 neighbors | Biswas & Ye 2004, §1 |
| Wrong distances used as measured | own choice (plain baseline) |

Known caveats: type B anchors are nearly collinear (mirror ambiguity); MDS takes 0.6–2.5 s on B–D.

## Reproduce the checks
Windows PowerShell, from the repository root, course package extracted into `course_package/`:
```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -B -c "
import sys, time; sys.path[:0] = ['course_package', '.']
import numpy as np, problem
from core.derivatives import Model
from core.initialization.baseline_initialization import mds_start, from_x0, random_start
for name in ['A_1', 'B_1', 'C_1', 'D_1']:
    p = problem.load(f'course_package/public/{name}.npz'); m = Model(p); x = random_start(p, 1)
    d = np.zeros_like(x); d[p.free] = np.random.default_rng(1).standard_normal((len(p.free), p.q)); h = 1e-6
    fd = (problem.objective(x + h*d, p) - problem.objective(x - h*d, p)) / (2*h)
    t = time.perf_counter(); xm = mds_start(p); t = time.perf_counter() - t
    print(name, 'grad rel err', abs(fd - np.vdot(m.gradient(x), d)) / abs(fd),
          'f(x0)', problem.objective(from_x0(p), p), 'f(MDS)', problem.objective(xm, p), f'{t:.2f}s')
"
```

Results on 8 public instances:
- `Model.objective` matches `problem.objective` exactly.
- Gradient matches Liam's `pgd.gradient` (~1e-18) and finite differences (~1e-8 relative). The Jacobian agrees with the gradient.
- MDS start is far better than `x0`: A_1 0.092 → 0.00034, B_1 6.0e-4 → 9.3e-6, C_1 1.1e-3 → 3.4e-5, D_1 1.7e-3 → 7.9e-5.

## Baselines implemented
- `baseline_solvers/pgd.py`: `run_pgd(param, x_start, deadline, record=None)`; `solver` = MDS start, then PGD. Armijo backtracking as in Liam's `pgd.py`.
- `baseline_solvers/levenberg_marquardt.py`: `run_lm(...)`; `solver` = LM from `x0`. Huber by IRLS weights, Marquardt scaling `diag(JᵀWJ)`, trial step projected, accepted only if the objective decreases.
- Tunable values live in `baseline_solvers/constants.py` (`TIME_FRACTION`, `PGD_*`, `LM_*`), read at call time: an experiment can set `constants.PGD_ARMIJO = ...` and call `run_pgd` directly. The course runner always uses the file's values.
- Both stop at 0.9·`max_time` and accept `record(x, iteration=, elapsed_s=)` (Liam's `Trace.record`).
- MDS is its own module `core/mds.py` (one function per MDS-MAP step); `mds_start` in `baseline_initialization.py` calls it. The empty `baseline_solvers/mds.py` was removed.

## Papers (`papers/`)
The handout cites the first three, only in "References" on p. 7 (after "To think about"); the slides must cover "what the literature says" (p. 2).

| Paper | What it gives us | Category |
|---|---|---|
| **Patwari et al. 2005**, *Locating the nodes* (survey) | Map of methods: MDS (no local minima, sensitive to range errors, O(n³)); multilateration from shortest-path ranges to anchors; successive per-node refinement; outlier (NLOS) detection by redundancy | Initialization, filtering, node fitting |
| **Shang et al. 2003**, *Localization from mere connectivity* (MDS-MAP; added by us, cited by Biswas–Ye and Patwari) | Our MDS baseline: shortest paths → classical MDS → anchor fit (`core/mds.py`) | Initialization |
| **Biswas & Ye 2004**, *SDP for ad hoc sensor localization* | Convex SDP relaxation; L1 error objective (some robustness). 50 sensors took 2–8 s (2004); estimates pulled to the anchors' convex hull (bad for type B's collinear anchors) | Initialization (patches), gradual solving |
| **So & Ye 2007**, *Theory of SDP for SNL* | SDP is exact for uniquely localizable networks; rigidity test; finds strongly localizable sub-networks. Wrong distances break these guarantees | Filtering (rigidity check), explanation |
