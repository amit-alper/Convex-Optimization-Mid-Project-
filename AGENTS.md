# Project workflow

- Create a separate Git branch for each task. Keep changes scoped to one milestone and verify that milestone before asking for review.
- Keep code simple, modular, readable, and easy for teammates to modify manually. Document the commands needed to reproduce each milestone.
- Have a teammate other than the author independently review the change and reproduce its checks before merging.
- Codex may commit, push, and open pull requests autonomously on task branches. Push to task branches only. Force-pushing is prohibited. Merging requires explicit human approval.
- Start the next milestone only after explicit human approval.
